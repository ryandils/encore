# Copy/paste prompt recipes

These are ordinary text files, not installed commands or automatically loaded skills. Open a recipe and paste it into your Codex interface with the repository selected.

- [Orient and learn](orient.md): understand the repo without editing it.
- [Take one task](implement.md): implement an explicitly selected deliverable.
- [Review before shipping](review.md): inspect a diff and its evidence.
- [Cloud orchestrator](cloud-orchestrator.md): run one explicitly scoped cloud chat with parallel subagents, in implementation or read-only investigation mode. Use [the cloud launch guide](../../docs/CLOUD_ENVIRONMENT.md) when starting several independent chats.

Persistent rules live in [AGENTS.md](../../AGENTS.md); the workflow lives in [the harness guide](../../docs/HARNESS.md). Replace bracketed values before use. Never paste secrets or real patron data.
