# Change handoffs

One new file per code/tooling/dependency/configuration PR: `<issue-or-task>-<short-description>.md`. Start from [TEMPLATE.md](TEMPLATE.md). Use a unique filename to reduce parallel-edit conflicts.

Keep each handoff brief and public-safe. It records evidence for its own change, not permanent current state. Read current code and [project context](../CONTEXT.md) before assuming old commands or limitations still apply. Git history/PR links provide dates and authors; no central chronological index needs editing for every task.
