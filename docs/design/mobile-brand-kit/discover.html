      How location would work

      A future “Use my location” action would explain the benefit before opening the browser prompt. Ask only after a user chooses it. Denied or unavailable permission returns to manual area search, without repeated prompts.

      Show approximate distances only with a known reference area and sufficient accuracy. Device permission changes belong in browser settings, not a pretend in-app switch.
