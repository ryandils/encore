TYPE THAT WORKS

Aa 084

System sans. Tight headlines. Tabular counts. No font downloads between an operator and the door.

16px body / 14px supporting / 48–88px count

SPACE TO ACT

64px

48px minimum interactive target; 64px preferred action height. Clear separation between free entry and exit.

4px spacing base / 16–24px page gutters

A VOICE WITH CONTROL

“Entry saved.”

Short, literal, neutral. Say what happened and what to do next. Never call recorded occupancy “live.”

No confetti. No blame. No false certainty.

Accessibility & implementation boundaries

High contrast is a design goal, not an accessibility certification. Primary white text on electric blue and violet is intentional; sky blue, periwinkle, and silver use black text. Do not use white body text on those lighter fills. Use text and icons alongside status colors.

This review uses native radio inputs, links, and disclosure controls. Illustrative product buttons are disabled. Real UI requires keyboard and screen-reader testing, zoom/reflow checks, reduced-motion support, physical phone trials, and server-backed permissions after shared contracts merge.

The standalone design does not implement issues #6, #7, #8, #9, or #10. The source of truth remains the repository product and architecture documents.
